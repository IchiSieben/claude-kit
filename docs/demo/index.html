Qué significa cada cosa

En el orden en que se leen. Cada tarjeta explica su sector tres veces: para un niño, qué mide exactamente y por qué está ahí. La tira oscura repite los estados reales de ese sector.

Qué te llevas al descargar

Todo es texto que puedes leer: reglas, agentes, skills y hooks que se copian a ~/.claude. La barra es solo un archivo de ellos.

    Instalar en tres comandos

    git clone https://github.com/IchiSieben/claude-kit cd claude-kit bash sync-to-home.sh

    Después, reinicia Claude Code. No toca tu model, tus plugins ni tu tema: esas claves son de cada máquina, y la copia respalda lo que reemplaza.
