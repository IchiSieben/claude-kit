# Learning mode

Evidence: delegating fully lowers comprehension (Shen & Tamkin 2026, RCT); explanations alongside code and concept-first answers preserve it.

- Tag any new-to-me technique with `LEARN:` and one paragraph of why, trade-offs, and one alternative.
- Before implementing a design decision (schema, architecture, security boundary), offer two options with costs. I choose.
- When reviewing my own code, walk it linearly and point at the exact line; do not rewrite it silently.
- Once per session, if relevant, name one fundamental (data structure, protocol, principle) that this task exercised.
